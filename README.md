# 📊 국방예산 분야별 & 신규사업 대시보드 웹 애플리케이션

본 웹 애플리케이션은 **국방예산 정부안 및 주요 중점투자사업 엑셀(.xlsx, .xls) 또는 CSV 데이터**를 입력받아, **분야별 재원 배분 현황**과 **신규사업 집중 분석**을 인터랙티브한 시각화 차트와 데이터 테이블로 제공하는 전문 대시보드입니다.

---

## 🚀 빠른 시작 (실행 방법)

### 1. 웹 브라우저에서 바로 열기
별도의 웹 서버 설치나 백엔드 구성 없이, `web` 폴더 안의 `index.html` 파일을 더블 클릭하여 크롬(Chrome), 엣지(Edge), 웨일(Whale) 등 최신 웹 브라우저로 바로 열 수 있습니다.

- 파일 경로: `c:\work1020\web\index.html`
- 주소창 입력: `file:///c:/work1020/web/index.html`

### 2. 로컬 웹 서버로 열기 (선택사항)
PowerShell 또는 간이 웹 서버를 통해 열고자 할 경우:
```powershell
cd c:\work1020\web
# PowerShell 기본 간이 서버 또는 라이브 서버 확장 사용 시
```

## 📋 지원 파일 및 서식 (Format)

### 1. 지원 파일 확장자
- **엑셀 워크북**: `.xlsx`, `.xls`
- **텍스트 데이터**: `.csv` (쉼표 구분, UTF-8 지원)

### 2. 표준 데이터 컬럼 구조 (헤더 자동 매핑)

| 열 (Col) | 권장 컬럼명 | 자동 감지 키워드 | 설명 | 예시 |
|:---:|:---|:---|:---|:---|
| **A** | `연번` | 연번, 순번, 번호, ID, No | 사업 일련번호 | `1`, `2`, `3` ... |
| **B** | `분야 (중점영역)` | 분야, 중점영역, 대분야, 영역 | 상위 분류 카테고리 | `① 자주국방 & 전작권 전환` |
| **C** | `세부 사업 / 주요 지표` | 세부 사업, 사업명, 세부사업, 항목 | 사업 또는 지표 명칭 | `피지컬 AI 실증사업` |
| **D** | `구분/단위` | 구분/단위, 단위, 구분, Unit | 금액 또는 수치 단위 | `억원`, `명`, `원` |
| **E** | `2026년 (A)` | 2026년, 2026, 전년, 기준, A | 전년도 기저 예산 수치 | `4968`, `0` |
| **F** | `2027년 정부안 (B)` | 2027년, 2027, 정부안, B | 당해년도(정부안) 예산 수치 | `7727`, `430` |
| **G** | `증감 (B-A)` | 증감, 증감액, B-A | 전년 대비 순증감액 (생략 시 자동계산) | `2759`, `430` |
| **H** | `증가율 (%)` | 증가율, 증감률, % | 전년 대비 증가율 또는 '신규' 표기 | `55.5%`, `신규` |
| **I** | `핵심 내용 및 보도자료 박스 원문 근거` | 원문, 핵심 내용, 근거, 비고, 설명 | 보도자료 박스 원문 근거 및 사업 세부내용 | `[신규 430억원] 수송·경계...` |

> 💡 **스마트 신규사업 자동 판별 기준**:
> 1. 증가율 열에 `'신규'` 또는 `'new'`가 포함된 경우
> 2. 2026년(전년도) 예산이 `0` 또는 공란이면서 2027년 예산이 편성된 경우
> 3. 사업명 또는 핵심 내용에 `'[신규'` 또는 `'신규 '`가 포함된 경우  
> 자동으로 **신규사업**으로 분류되어 **신규사업 집중 분석관(Special Spotlight)** 및 전용 뱃지가 부여됩니다.

## 🌟 주요 기능 안내

### 1. 종합 요약 (Executive Summary & KPIs)
- 2027년 정부안 총액 (조원 환산 표기 병행)
- 전년 대비 순증감액 및 전체 증가율
- 분석 대상 사업 총 건수 (신규 건수 / 계속 건수 구분)
- **신규사업 총 투자규모 및 전체 예산 대비 비중(%)**
- 최대 투자 중점 분야 및 점유율

### 2. 인터랙티브 비주얼 차트
- **분야별 예산 비교 (Grouped Bar Chart)**: 각 중점영역별 2026년 vs 2027년 예산 막대 비교
- **분야별 재원 점유율 (Donut Chart)**: 전체 파이 중 각 분야가 차지하는 비중(%)
- **신규 사업별 투자 규모 순위 (Horizontal Bar Chart)**: 신규 편성된 사업들의 예산 순위 TOP
- **분야별 신규사업 예산 분포 (Donut Chart)**: 신규 투자가 어느 분야에 집중되었는지 한눈에 파악

### 3. 분야별(중점영역) 상세 분석 아코디언 카드
- 각 분야별 카드에서 **'27 정부안 총액, 증감액, 증감률, 전체 재원 점유율 프로그레스 바** 확인
- 카드를 클릭하여 **해당 분야에 속한 세부 사업 목록 및 원문 근거 펼치기/접기**
- `[표 필터링]` 버튼으로 하단 데이터 표에서 해당 분야 데이터만 원클릭 필터링

### 4. 🚀 신규사업 집중 분석관 (New Projects Spotlight)
- 2027년도에 신규 착수되는 모든 전략 사업들을 전용 카드 그리드로 하이라이트
- 신규 사업명, 소속 분야, 투자 금액, 핵심 내용 및 보도자료 원문 근거 직관적 표시

### 5. 세부 사업 전체 데이터 탐색기
- **실시간 검색**: 사업명, 분야명, 핵심 내용 텍스트 실시간 필터링
- **원클릭 필터 필(Pill)**: `[전체]`, `[🚀 신규사업만]`, `[계속사업만]`
- **분야별 드롭다운 필터**: 원하는 분야만 선택하여 조회
- **동적 열 정렬(Sort)**: 연번, 분야, 사업명, 2026년, 2027년, 증감액, 증가율 헤더 클릭 시 오름차순/내림차순 정렬
- **상세 모달 팝업**: 행 클릭 시 해당 사업의 전체 지표와 장문의 보도자료 원문 근거를 큰 팝업으로 열람

### 6. 데이터 입출력 & 편의 기능
- **드래그 앤 드롭 업로더**: 파일 창에서 엑셀/CSV 파일을 웹 브라우저로 바로 끌어다 놓아 갱신
- **표준 서식 다운로드**: 사용자가 새로운 데이터를 채워 넣을 수 있는 `CSV 템플릿 다운로드`
- **데이터 내보내기**: 현재 화면에 필터링된 데이터를 즉시 `CSV` 또는 `Excel(.xlsx)`로 다운로드
- **샘플 복원**: 언제든지 원본 2027년 국방예산안 데이터로 원클릭 복원
- **다크 / 라이트 테마 전환**: 우측 상단 달/해 아이콘 클릭으로 다크모드/라이트모드 토글
- **보고서 인쇄 및 PDF 저장**: 브라우저 인쇄(`Ctrl+P` 또는 프린터 아이콘)에 최적화된 리포트 출력 스타일 제공
